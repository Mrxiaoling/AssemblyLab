# PRD — Assembly Lab 产品需求文档

> Phase 0 设计文档 · 状态:待确认
> 上游需求:README 全文。本文档将其收敛为可执行的产品定义与验收框架。

## 1. 愿景与定位

**Assembly Lab 是一个「以真实执行为核心」的汇编语言交互式学习平台**:每个原理都必须有可运行、可观察、可修改、可验证的实验(README 最重要的验收原则)。

它不是教程网站,也不是玩具模拟器:
- 比教程网站多了**真实执行**(真实汇编器 + 模拟器/调试器 + 状态可视化)。
- 比玩具模拟器多了**与 C++/编译器/ABI 的联系**与**系统化的课程-习题闭环**。

## 2. 目标用户

- 有 C/C++ 经验、汇编不系统的开发者(主要画像)。
- 关键既有能力:读 C++、理解变量/指针/函数;需建立:指令级执行模型、ABI、底层机制(协程/上下文切换/异常/中断)。

## 3. 核心学习循环(产品设计的第一性约束)

每节课都必须让用户走完这个循环,UI 与课程结构都为它服务:

```
真实问题 → 运行程序 → 看汇编 → 逐指令执行 → 观察寄存器/内存/栈/标志
        → 可视化理解 → 修改代码并预测 → 执行验证 → 习题 → 综合项目
```

UI 落点:实验工作台的每个面板 + 解释卡 + 习题反馈,都对应循环中的环节(COURSE_DESIGN.md 15 步模板)。

## 5. 关键用户故事(P1 验收用)

1. **US-1 逐指令观察**:「我粘贴一段 NASM 程序,能单步执行,每一步都看到哪些寄存器/标志/内存变了、为什么变。」
2. **US-2 修改与验证**:「我改一个立即数重新汇编,预测结果,再单步验证;我的预测和真实执行逐项对比。」
3. **US-3 断点与轨迹**:「我在任意行设断点运行,停下后能回看每一步的执行轨迹。」
4. **US-4 课程闭环**:「我完成一课的动手实验(校验通过)和课后习题(判题反馈),首页进度与推荐更新。」
5. **US-5 离线**:「断网时 US-1~4 全部可用。」

## 6. 非功能需求

| 维度 | 要求 |
|---|---|
| 真实性 | 状态变化必须来自真实执行引擎;解释可错、执行不可错(分层见 ARCHITECTURE §4) |
| 安全性 | 按不可信输入处理用户代码(SECURITY_DESIGN);不安全模式显式禁用 |
| 离线 | 核心课程/实验/判题零联网;AI 为唯一可选联网组件 |
| 性能 | 单步 < 50ms;万步 run < 2s(TEST_PLAN §8) |
| 可维护 | ISA 适配器化、教学内容数据化、接口有文档、决策有记录 |
| 平台 | 本地部署:桌面浏览器 + localhost 后端;Windows 优先,WSL2 增强 |

## 7. MVP(Phase 1)定义

**一句话:** 用户在浏览器里对一个 x86-64 汇编程序做「汇编 → 逐指令执行 → 观察每条指令的寄存器/标志/内存 diff 与解释 → 设断点 → 改代码重来」的完整循环,配 3 节课与 2 种可判题习题,全程离线。

**MVP 明确不含:** C++ 编译、真实调试器、ARM64、栈帧可视化(P1 先有栈内存视图)、协程、AI。

**MVP 验收清单(对应 README 十五节 1–4、10、11、13):**
1. 输入汇编并编译运行(真实 nasm + Unicorn)✅
2. 逐条执行指令 ✅
3. 观察寄存器变化(含执行前后对比与解释)✅
4. 观察内存变化(hex 视图 + 写入事件)✅
10. 完成实验并获得自动反馈(动手实验校验)✅
11. 通过课后习题检验(预测/补全两种题型,确定性判题)✅
13. 离线使用核心课程和实验 ✅

## 8. 非目标(Explicit Non-Goals)

- 不做云服务/多用户/账号体系。
- 不做通用 IDE;编辑器只服务学习场景。
- 不模拟微架构(流水线/缓存时序/分支预测)——模拟的是**指令语义**;涉及性能的教学点用测量真实硬件的旁证数据,并明确标注。
- 不支持 32 位保护模式/实模式(记录为远期可选项)。
- 不内置完整 C++ 教学内容;C++ 只作对照。

## 10. 决策记录

| # | 决策 | 理由 |
|---|---|---|
| D-PR-1 | MVP = 模拟器模式 + 3 课 + 2 题型,不含 C++ | 最快打通「真实执行 + 观察闭环」这一最高风险假设;README Phase 1 定义一致 |
| D-PR-2 | 平台以「教学沙箱内存布局」呈现(明确标注),而非真实进程地址空间 | 模拟器模式的结构性隔离需要;进程级真实布局由模式 B(P2)承担,两模式差异如实展示 |
| D-PR-3 | AI 是增强不是依赖 | README 第九节;判题确定性优先 |
